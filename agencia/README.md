# Agencia · guía rápida de uso

Esta carpeta es la **mesa de trabajo** de la agencia. Todo el trabajo por producto
vive en `productos/<id>/`.

## Para arrancar

1. Abre una sesión con el agente **Director General** (es el primario).
2. Mándale el producto: **fotos + lo que sepas** (qué es, estado, dueño, precio que
   pide el dueño si lo sabes, y si la comisión es fija o libre).
3. El Director reparte el trabajo entre los subagentes y te devuelve el paquete
   listo para publicar.
4. Tú copias y pegas en **Revolico** y en los **grupos de Facebook**.

## Carpetas

- `config/politica.md` — las reglas del negocio.
- `proveedores/` — un folder por dueño, con su ficha y **sus vales**.
- `productos/` — un folder por producto con todo el proceso.
- `plantillas/` — modelos de mensajes y copy.

## Regla de oro del vale

Cada dueño tiene **su propio vale**. Al gestionar una venta, se usa el vale **de
ese dueño**. Si es un dueño nuevo, pásale su vale al Director para guardarlo.
